# Calculator
This is a simple calculator for performing basic arithmetic operations

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Posituve, negative symbol button(if clicked, - appear)
- Clear button
- Responsive frontend design
- interactive button effects

## Technology used
- HTML5
- CSS
- Javascript


## How to use it
- Click the calculator button for calculations to be made
- Click the arithmetic operations signs to perform task
- Add decimal if needed
- Click equal (=) button to display the result
- Use AC button to clear inputs

Project Structure
- calculator/
- index.html
- style.css
- calculator.js
